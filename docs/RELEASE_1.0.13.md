# Release 1.0.13 — Final Repository Documentation

This release documents the current repository as it actually operates:

- shared millimeter-polyline architecture;
- built-in centerline fonts and selected-font behavior;
- experimental outline-to-centerline conversion and its limits;
- Graves handwriting controls, cleanup, wrapping, and multi-line placement;
- preview invalidation and Stop rendering behavior;
- one-server operation and the correct neural environment command; and
- the division between Python rendering, G-code, Marlin, and the ESP32 bridge.

No rendering behavior is changed by this release.
